# BeBeans – sito pubblico

Sito vetrina di BeBeans (bebeans.it): l'app di famiglia che trasforma i compiti di casa dei ragazzi in un gioco.

- `index.html` – home page (pagina unica, nessuna dipendenza da build)
- `privacy.html` – informativa privacy (provvisoria)

Sito statico: si pubblica così com'è su Cloudflare Pages o GitHub Pages, senza comando di build.
L'indirizzo email di contatto si cambia nella costante `EMAIL` in fondo a `index.html`.
